# Customer Churn Analysis | Power BI

## 📊 Project Overview

This project analyzes customer churn using Microsoft Power BI.

The dashboard helps identify customer churn patterns, understand key churn drivers, identify high-risk customer segments, and estimate monthly revenue at risk.

## 🎯 Business Objectives

- Measure overall customer churn rate
- Identify customers who are more likely to churn
- Analyze churn by contract type
- Analyze churn by internet service
- Analyze churn by payment method
- Understand the relationship between tenure and churn
- Identify high-risk customer segments
- Estimate monthly revenue at risk
- Provide customer retention recommendations

## 📁 Dataset

The dataset contains customer information including:

- Customer ID
- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Contract
- Internet Service
- Payment Method
- Monthly Charges
- Total Charges
- Churn

Total dataset records: **7,048**

## 💡 Key Business Recommendations

- Encourage month-to-month customers to move to longer-term contracts
- Improve onboarding for new customers
- Review pricing and package value for high-charge customers
- Encourage automatic payment methods
- Investigate service quality for high-churn service segments
- Prioritize high-value customers for personalized retention campaigns
